# pieraksts

Booking pages for small Latvian businesses. One folder per client, served by GitHub Pages
from the default branch: <https://4n45f86dyg-creator.github.io/pieraksts/>.

Every page is generated by `build_page.py` in the private HQ repo
(`employees/front-desk/tools/build_page.py`) from one JSON config per client. Nothing in
this repo is edited by hand — a change means rebuild and push.

Bookings are delivered by Web3Forms: the form posts to `api.web3forms.com`, Web3Forms
emails the booking to the business, then sends the visitor to that client's own
`/<client>/paldies/` confirmation page. The `access_key` in the HTML is a public
Web3Forms key by design — it identifies a mailbox, it grants access to nothing.

Slots shown as taken are a build-time snapshot from a hand-kept `<client>.booked.json`.
Web3Forms has no public read API, so nothing syncs by itself: the business seeing the
booking email is what prevents double bookings.
